# Manbalar

"Turistik korxonalar faoliyati tahlili" fani bo'yicha platforma uchun boshlang'ich materiallar shu papkaga yuklanadi:

- O'quv qo'llanma / ma'ruzalar matni (.docx)
- Testlarning to'g'ri javoblari
- Fan dasturi (sillabus)
- Amaliy mashg'ulotlar, keyslar, korxona ko'rsatkichlari
- Kasb standarti / kompetensiyalar
- Taqdimotlar (PDF/PPTX), rasmlar, video havolalar

Yuklash: GitHub'da shu papkani oching → **Add file → Upload files** → fayllarni sudrab tashlang → **Commit changes**.
